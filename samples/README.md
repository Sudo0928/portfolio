# 코드 샘플

원본 프로젝트가 에셋 라이선스 문제로 비공개라, 제가 작성한 코드만 팀 동의하에 발췌해 두었습니다. 각 폴더의 README에 **어떤 게임인지**와 **저작 범위**, 그리고 있다면 **한계**까지 적었습니다.

| 폴더 | 출처 | 내용 |
|---|---|---|
| [`raid-network-core/`](./raid-network-core) | ProjectRAID (비공개) | 헌팅 액션 RPG의 서버 권위 네트워크 코어 — 도메인별 시스템, 유저 데이터 동기화, 종료 핸드셰이크, 씬 부트스트래퍼 |
| [`raid-behaviour-tree/`](./raid-behaviour-tree) | ProjectRAID (비공개) | 동행 NPC의 두뇌 — 외부 에셋 없이 직접 설계한 ScriptableObject 기반 Behavior Tree (73개 스크립트) |
| [`netcode-prediction/`](./netcode-prediction) | 개인 프로토타입 (비공개) | 예측/보정 실험. **혼자일 때만 동작하고 멀티에서는 떨립니다** — 원인 세 가지를 코드 위치와 함께 적었습니다 |

## 공통 고지

- **읽기용 발췌입니다.** 서드파티 라이브러리(FishNet, Odin Inspector, ECM2 등)의 소스는 포함하지 않았으므로 이 폴더만으로는 컴파일되지 않습니다. 서드파티는 `using`으로 참조만 합니다.
- 저작 범위(단독/주도/공동)를 폴더마다 정직하게 적었습니다. 팀 프로젝트 코드는 팀 동의를 받아 발췌했습니다.
- 전체 맥락은 포트폴리오 사이트의 프로젝트 상세 페이지에 있습니다.
